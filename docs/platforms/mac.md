# Mac

On Apple silicon Macs, Quartermaster runs as the same app, with a layout made for the Mac:

- A **sidebar** to switch worlds, in place of the slider
- Layouts that fit the window, with wider grids
- In wide windows, Command Centre layouts use **two columns**
- The **Today** card sits in the spotlight
- **Keyboard shortcuts**
- Click outside a sheet to close it

## Keyboard shortcuts

| Shortcut | What it does |
|---|---|
| ++cmd+1++ to ++cmd+9++ | Go to Home, then each item in the sidebar, in order |
| ++cmd+f++ | Search |
| ++cmd+comma++ | Settings |
| ++cmd+r++ | Refresh the screen you're on, where it can refresh |
| ++cmd+bracket-left++ | Back |
| ++ctrl+cmd+s++ | Show or hide the sidebar |
| ++cmd+s++ | Save, in a form |
| ++enter++ | Open the selected item |
| ++esc++ | Close a sheet |

In the player:

| Shortcut | What it does |
|---|---|
| ++space++ | Play or pause |
| ++arrow-left++ / ++arrow-right++ | Skip back or forward |
| ++f++ or ++ctrl+cmd+f++ | Full screen |
| ++s++ | Skip the intro |
| ++esc++ | Close the player |

The same shortcuts work on an iPad with a keyboard, apart from showing or hiding the sidebar.
