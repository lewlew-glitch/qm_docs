# Getting started

Setup takes a few minutes:

1. **[Check the requirements](requirements.md):** an Apple device and at least one self-hosted service.
2. **[Install the app](install.md)** from the App Store.
3. **[Add your first service](first-service.md).** The free tier connects one service fully.
4. **[Set up home and away addresses](home-and-away.md)** so Quartermaster works when you're out.
5. *(Optional)* **[Install QM Companion](../companion/index.md)** on your Docker host to see containers and stacks. With Pro, you can also import every service in one go.

!!! tip "Already run QM Companion?"
    With Pro, a fresh install can pull in your whole service list with [stack handover](../companion/stack-handover.md). You don't have to add services one at a time.
