# Install the app

Quartermaster is on the App Store as **Quartermaster Homelab Stack**.

[Download on the App Store](https://apps.apple.com/gb/app/quartermaster-homelab-stack/id6779994284){ .md-button .md-button--primary }

One purchase covers iPhone, iPad and Apple silicon Macs.

## First launch

Quartermaster has no account to create and no sign-in. When it opens, you can:

- **Add a service** by hand. See [Add your first service](first-service.md).
- **Import from QM Companion** using a setup transfer (QR code, `.qmcompanion` file or one-time code). See [Pair a device](../companion/pairing.md).
- **Restore from iCloud Sync**, if you've used Quartermaster on another device. See [Sync and backups](../reference/sync-backups.md).

## Choose where the app opens

In **Settings → General → Open the app on**, pick **Where you left off**, **Entertainment** or **Command Centre**. It takes effect the next time the app starts.
