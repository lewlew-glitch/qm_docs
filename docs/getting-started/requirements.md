# Requirements

## Devices

| Device | Status |
|---|---|
| iPhone | iOS 16.4 or later |
| iPad | iPadOS 16.4 or later |
| Mac | macOS 12.0 or later, on a Mac with Apple M1 or later. It's the same app, with a sidebar layout |
| Apple TV | tvOS 18 or later. Beta via TestFlight. See [Apple TV](../platforms/apple-tv.md) |

## Your server

- A self-hosted server running the services you want to connect. See the [supported services](../services/index.md).
- An API key or login for each service.
- **QM Companion** *(optional)* needs Docker on the host.

## Remote access *(optional)*

To use Quartermaster away from home, you need a way to reach your services, such as **Tailscale**, a VPN or a reverse proxy. See [Home and away](home-and-away.md).
