# Stack handover *(Pro)*

Stack handover lets a **fresh install** of Quartermaster import your whole service list from Companion. You don't have to add services one by one.

1. In Companion, create a **one-time code**.
2. In a new Quartermaster install, choose to import from Companion and enter the code.
3. **Check each service's address** before you finish.

This is useful for a new phone, a family member's iPad or a reset device.
