# QM Reader

*New in 1.3.* QM Reader is a third world for **books and audiobooks**. It combines titles from **BookOrbit** and **Grimmory** into one library.

Turn it off in **Settings → Media & Reader → QM Reader** if you don't need it.

## Reading

EPUB and PDF open in a native reader with:

- **Paged** or **scrolling** modes
- Adjustable text size and spacing
- Themes, including a true **Black** theme
- Fonts, including **OpenDyslexic**

## Audiobooks *(BookOrbit)*

- Playback speed
- Sleep timer
- Chapters
- Mini player
- Background playback
- Progress syncs back to BookOrbit

## Library

You see collections, series and read status from both servers. BookOrbit adds star ratings, highlights, notes and reading stats.

## Discover and request

Add an optional **Hardcover** API key to see trending books, charts and new releases. You can request titles through **BookOrbit** by title, ISBN or author.
