# Command Centre services

## Containers and orchestration

| Service | What it does |
|---|---|
| **Portainer** | Docker management |
| **Dockhand** | Docker management |
| **Komodo** | Build and deployment management |
| **Coolify** | Self-hosted app platform |
| **Arcane** | Docker management |
| **Dozzle** | Live container logs |
| **QM Companion** | Containers, stacks, volumes and updates. See [QM Companion](../companion/index.md) |

## Hypervisors and NAS

| Service | What it does |
|---|---|
| **Proxmox VE** | Hypervisor. Machine stats |
| **Unraid** | (7.3 or later). Array, disks, shares, live stats and UPS. Start, stop and update containers |
| **TrueNAS** | NAS. Machine stats |
| **Synology** | NAS. Machine stats |
| **UGREEN NAS** | NAS. Machine stats |

## Host monitoring

| Service | What it does |
|---|---|
| **Glances** | CPU, memory, temperature and drives |
| **Beszel** | Lightweight host stats |
| **Scrutiny** | Drive S.M.A.R.T. health |
| **PeaNUT** | UPS status, battery and load, with opt-in battery alerts. *New in 1.3* |

## Uptime and dashboards

| Service | What it does |
|---|---|
| **Uptime Kuma** | Status, response times, certificate warnings and uptime (Kuma 2). Down and recovery pushes with Pro. *New in 1.3* |
| **Grafana** | Browse dashboards with an optional Viewer token, or open the full web app in Quartermaster. *New in 1.3* |
