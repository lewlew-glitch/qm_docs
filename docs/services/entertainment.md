# Entertainment services

## Media servers

| Service | What it does |
|---|---|
| **Plex** | Media server. Browse and play in the app |
| **Jellyfin** | Media server. Play in the app, per-user Up Next and Continue Watching, Now Playing. Apple TV beta |
| **Emby** | Media server. Play in the app and choose whose titles appear on Home. Apple TV beta |

## Library management

| Service | What it does |
|---|---|
| **Radarr** | Finds and manages films |
| **Sonarr** | Finds and manages TV series |
| **Lidarr** | Finds and manages music |
| **Bazarr** | Downloads subtitles for films and TV |
| **Maintainerr** | Rule-based library clean-up. *Keep forever* removes a title from Leaving Soon immediately |
| **Shelfarr** | Book and audiobook requests |

## Download clients

| **NZBGet** | Usenet downloader |
| **qBittorrent** | Torrent client |
| **Transmission** | Torrent client |
| **Deluge** | Torrent client |

## Indexers

| Service | What it does |
|---|---|
| **Prowlarr** | Indexer manager for the *arr apps |
| **NZBHydra2** | Usenet indexer meta-search |
| **Jackett** | Torrent indexer proxy |

## Requests and discovery

| Service | What it does |
|---|---|
| **Seerr** | Requests, Trending rows on Home, family and friends sharing. Jellyseerr and Overseerr still work, but are no longer maintained, so we recommend moving to Seerr |
| **Pulsarr** | Approve or reject requests, manage rolling shows, push on new request. *New in 1.3* |
| **DroppedNeedle** | Music requests |
| **Wizarr** | Invites users to your media server |
| **ReadMeABook** | Audiobook requests |
